# 🫀 Heart Disease Classification & Prediction App

A Machine Learning-based web application designed to predict the likelihood of heart disease in patients based on clinical indicators and medical features.

---

## 📌 Overview

This project leverages machine learning algorithms to perform early risk assessment for heart disease. By analyzing patient health metrics such as age, blood pressure, cholesterol levels, and maximum heart rate, the model provides immediate predictive insights through an interactive web interface.

---

## 🛠️ Tech Stack & Tools

- **Programming Language:** Python
- **Data Processing & Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn, XGBoost
- **Data Visualization:** Matplotlib, Seaborn
- **Web Framework / UI:** Streamlit

---

## 📊 Key Features

- **Interactive Input Form:** Allows users/clinicians to input patient parameters easily.
- **Real-time Prediction:** Generates immediate risk probability assessments.
- **Model Explainability:** Visual representations of feature importance and decision boundaries.
- **High Performance:** Model fine-tuned for high **Recall** to minimize false negatives in clinical predictions.
